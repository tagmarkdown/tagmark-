# tagmark
这是一个图片管理软件

用途：快速通过记忆碎片检索图片

代价：提前标注图片

## ⚠警告⚠

release版为纯ai生成，没有做人工代码审查，也没有修bug，建议在虚拟机中运行，以避免意料之外的损害。

此版本为测试版。不建议用来实际整理照片，仅做功能验证。

### 一、软件功能

1.导入

支持批量导入，通过md5去重。此版本不会移动文件，仅记录路径。数据库应该只存储标签。

2.标注

将标签组合为断言，以断言标注图中对象，可通过方框框选对象。标签暂定五类，对象、属性、部件、关系、元数据，可按规则组合。
标签以三元组形式组合为断言（举例：龙：舔：猫），也可以二元组形式组合为断言（龙：毛茸茸），可嵌套（龙：毛茸茸：舔：猫）。
支持“智能文件夹”，可将图片移入图池或漫画集合。
    
3.检索 

组合不同标签为断言进行检索。支持语法糖，检索语法以冒号连接，如狗：舔：猫。支持别名，条件组合，包含，排除，计数，嵌套语法查询
    
4.导出 

以文件夹形式导出检索后筛选出的图片

5.标签管理

组织标签，删改标签。
属性标签以二元组分类，形式为 名称：属性。名称不参与检索，只作为分类方式
举例 颜色：白色 体表：毛茸茸，颜色，体表本身不参与检索。
颜色下属有各种颜色，颜色只作为分类名，不作参与检索。

### 二、使用方法

下载解压release中的压缩包，双击tagmark.exe即可使用，程序运行会向C:\Users\<你的用户名>\AppData\Roaming\tagmark路径下写入数据库（标签管理相关）相关的文件，目前版本不会移动导入的图片。删除源路径图片会导致软件无法访问图片。

### 三、软件规划

1.导入

细化文件重名情况下的处理方法

2.标注

自动检测，确保标签树为有向无环图，集合成员的断言作为集合断言，方便检索集合（漫画，图池）。

3.检索

优化检索语法，优化语法糖，确定检索方法。

5.管理

以标签标注标签，聚合标签为知识图谱，实现标签带入，标签错误检测的功能。
以标签形式，建成角色知识图谱，实现自动带入标签的功能
举例：标注罗小黑（角色）自动带入罗小黑战记（系列）
数据库管理，支持将图片移入软件数据库，软件数据库分为文件库和标签库。可能会将标签组织形式（知识图谱）存入第三个数据库？或者存在标签数据库中
    
#### 用标签标注标签含义，用标签组织知识图谱，用分好类的标签，组合为断言，用断言标注对象，实现图片的完美分类。
